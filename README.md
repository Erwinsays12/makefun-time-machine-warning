## What it does

`main.ts` writes a single original one-line warning label for a time machine — the funniest one it can muster — to `/output/entry.txt`.

The label:

> WARNING: Never meet your past self. He knows what you did, and he has had years to plan his revenge.

It is phrased like a genuine safety notice, turns the real hazard of meeting your duplicate self into the joke, and saves the surprise — years spent planning revenge — for the last few words.

## Run

```sh
node main.ts
```

The program is deterministic: it always writes the same line, 100 characters, well within the 120-character limit.
